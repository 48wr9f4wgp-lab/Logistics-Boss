# FORGE v0.5 — 工場画面から設備を操作

## Goal / scope
機械をタップしても全設備一覧に飛び、選択した設備が特定されない問題を解消する。
機械の画面上の立体・ラベルを選択し、担当者、同種工程の待ち数、現在の運搬経路を表示する。
工場画面の選択カードから移動・改良・詳細へ進む。工程待ちボタンからも設備を選べる。
経済、シミュレーション、セーブ形式、既存FLOTRAは変更しない。

## Acceptance
- 機械の上部・正面・ラベルをタップして正しい設備が選べる。選択だけでは生産を止めない。
- 同種の設備が複数ある場合は工程ボタンの再選択で順番に選べる。
- 担当者の状態と同種工程全体の数を区別し、実際の残り運搬経路を描く。
- 改良、移動中の工程終了待ち、配置・取消が既存の処理を通る。
- 詳細画面では選択設備を先頭に表示する。
- 390×844で選択カード・速度・工程ボタンが操作できる。

## Checks / visual proof
既存モデル回帰テスト、画面座標のヒット判定テスト、構文検査。
クラウドChromiumで設備選択、工程ボタン、改良、移動・取消、詳細を操作。
画面証拠を evidence に保存する。実機iPhoneの検証とは区別する。
