# マチコバ！ v0.17　工場の昼光と加工の手元

通常倍率では道路側の台座から屋上の集じん機まで収まる。工場の幅に合わせて構図を切り替え、機械と職人はタイルの中心を基準に描く。管理や操作を開かずに仕事を進める画面構成を引き継いだ。

## 作業風景

型板ガラス越しに近隣工場の屋根、遠景の稜線、電線が見える。窓の光、床の目地、磨り減った緑の搬送通路、鋳鉄の排水蓋、れんがと金属の境目を小さな画面でも読めるようにした。壁のホーロー看板は手描きの字形を使う。

切断機の砥石カバー、ボール盤のモーターカバー、旋盤の油面計、検品台の測定工具を個別に造形した。加工中の作業面に手元灯が当たる。切断時は火花、ボール盤と旋盤は機構に連動した小さな切りくずが出る。職人の作業着、姿勢ごとの投影も作り直した。

プレートとシャフトはそれぞれ素材・切断後・穴あけ／旋削後の三形態。手の中、工程待ちのトレー、機械の上で同じ部品モデルを使う。加工が止まると手と機構が同じ位置で止まる。「動きを減らす」では加工片の飛散を省く。

## 再生成と確認

既存のオフライン生成器を使う。対象名には rooms / machines / crew / station を指定できる。

```sh
python factory-prototype/art-source/miniature.py /tmp/machikoba-bake docs/forge-preview/art station
node --test factory-prototype/tests/*.test.mjs
```

機種ごとの画像範囲、工程に対応する部品、画像読み込み失敗、拡張直後に古い床が遅れて届く場合、両サイズの全景とズームの座標を検証する。モバイルブラウザー確認では受注・加工・出荷、ピンチ、設備移設・購入を通す。実機の発熱、長時間のフレームレートは未計測。
